
# Taxi Order Management System

## Project Description
Java тілінде жасалған такси тапсырыстарын басқару жүйесі.

Жүйе клиентке такси тапсырыс беруге, жүргізушіні таңдауға, жол ақысын есептеуге және тапсырыс күйін бақылауға мүмкіндік береді.

## Main Features
- Taxi order creation
- Economy and Comfort taxi
- Driver selection
- Automatic price calculation
- Order status notifications
- Cash and card payment
- Order management

## Design Patterns
1. Singleton
2. Factory
3. Strategy
4. Observer
5. Builder

## SOLID Principles
- SRP – әр класс бір міндет атқарады.
- OCP – жаңа тарифтерді қосуға болады.
- LSP – EconomyTaxi және ComfortTaxi Taxi класын алмастырады.
- ISP – шағын интерфейстер қолданылады.
- DIP – OrderService интерфейске тәуелді.

## Technologies
- Java
- OOP
- SOLID
- Design Patterns
